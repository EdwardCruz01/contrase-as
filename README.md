# BOTS · Gestión de cuentas

Abre `index.html` en el navegador. Acceso inicial: usuario `Edward01`, contraseña `ARmando01`.

Para activar la base de datos, ejecuta `supabase-schema.sql` en el SQL Editor de Supabase. La aplicación ya tiene configurada la URL REST y la clave publishable proporcionadas.

Nota: este prototipo guarda contraseñas en texto plano y usa un login del lado del navegador. No debe publicarse así para uso real; la siguiente mejora debe ser Supabase Auth, cifrado/gestión de secretos y políticas RLS por usuario.
